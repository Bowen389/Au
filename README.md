# PAXGUSDT 日线策略研究 + 自动金额模拟盘 + GitHub Issue 推送

> 研究数据截至 **2026-09-27 UTC**，在 2026-09-28 UTC 尚未收盘时生成。数据源：[Binance PAXGUSDT 日线公开 K 线 API](https://data-api.binance.vision/api/v3/klines?symbol=PAXGUSDT&interval=1d&limit=2)，本项目用 `startTime/endTime/limit` 分页。币安 `data-api.binance.vision` 是公开**现货交易对行情接口**，**PAXGUSDT 并非伦敦现货黄金 XAU/USD**：它是 PAXG 代币相对 USDT 的报价，包含代币、稳定币、交易所、流动性与价格偏离风险。此工具仅模拟成交并生成通知，不是投资建议，不真实下单，也无法保证最大回撤一定低于 30%。

## 唯一上线规则

1. 北京时间每日 **08:00 / 日本 09:00** 完成 UTC 日 K；**08:20 / 09:20** GitHub Actions 尝试运行（可能延迟）。仅用最新**已收盘**日 K：EMA10 > EMA50 目标 PAXG 仓位 100%，否则 0%。信号产生后才在**下一交易时段**人工执行；回测使用次日 UTC 开盘，实盘晚到的价格可能不同。
2. 账户本地风险峰值回撤 ≥12%/18%/22% 时仓位上限 75%/50%/25%，≥25% 触发空仓冷却；10 个日信号后且 `close > SMA200`、20 日动量为正才解除并重置**风控周期峰值**（不重置业绩回撤）。账户权益 ≤初始资金的 70% 时锁死、下个可交易开盘尽量清仓；净值跳空时可能穿越 30%。所有风控只在收盘后执行，**不是盘中止损或最大亏损保证**。
3. 目标与当前仓位差 ≥10 个百分点才调仓；但目标 0 须全部卖出、空仓转入非零目标须买入。无杠杆、不做空、仅使用账户现金和持币数量。建议金额按昨日收盘估算，不视作限价或保证成交额。PAXG/USDT 而非美元，需使用 USDT 账户。

## 自动金额模拟盘（本次新增）

你选的是 **从 2026-02-01 的 10,000 USDT 起，自动算每笔买卖金额、自动更新模拟持仓与资金、每天发通知；不连接交易所，不真实下单**。仓库已经附带 `paper_portfolio.json`：截至 2026-09-27 完整日线历史回填结果现金 **9,804.82 USDT**、PAXG **0**；2026-09-28 的首次模拟推送为**模拟持有，买卖金额 0 USDT**。历史回填四笔均以次日 UTC **开盘价**假设成交、每边 0.15% 成本；具体数字和价格在 `paper_fills.csv`。**历史回填是事后重建，不是当时真的发过通知或成交。**

后续每日 UTC 00:20 左右（北京时间 08:20、日本 09:20）运行：读取前一根完整日 K 计算 EMA 和风险仓位；读取运行时币安公开最新 PAXGUSDT 报价，按模拟现金和持币计算买卖金额，在模拟盘中立即入账（含单边 0.15% 假设成本），发送 GitHub Issue。当天重复运行不会重复买卖。运行时的公开报价是**快照，不是实际委托成交价**，它也不同于研究回测采用的“次日 UTC 开盘价”；未来模拟曲线不能与旧回测结果当作同一成交口径。不支持真实下单或资金划转。

```bash
pip install -r requirements.txt
python paper.py                          # 在线更新模拟盘 + 自动填金额/记账/写 signal_latest.txt
python post_issue.py success --dry-run   # 预览 Issue 文本，不发送
python data.py                           # 更新完整日 K
python research.py                       # 重跑历史研究（不自动改写模拟盘）
python -m pytest -q tests                # 可选：需另安装 pytest
```

本目录的**模拟账本已初始化**，不要再次 `--init` 覆盖。若要创建自己的不同起始本金/日期，先另存/移走旧账本与旧交易流水，在**新的独立仓库**运行 `python paper.py --init <USDT本金> --start YYYY-MM-DD`；它将从该日起回填历史，不能作为真实资金收益凭证。只改 `paper_portfolio.json` 的本金数字会使仓位和风险历史错误。不要将模拟盘余额当成交易所余额。`daily.py` 是保留的手工登记实验工具，与这个**自动模拟工作流无关**，不得把它的 `portfolio.json` 混入模拟盘。

## GitHub Issue 自动推送部署

通知机制参考 [Bowen389/btc](https://github.com/Bowen389/btc)，本次改为**自动模拟记账**，每次推送会明示“纯模拟 / 非真实成交”。

1. 将项目完整上传至你的 GitHub **Private** 仓库，包含 `.github/workflows/paxg.yml`、`paper_portfolio.json` 与 `paper_fills.csv`。Settings → General 打开 Issues；Settings → Actions → General → Workflow permissions 选 **Read and write permissions**。
2. Actions → **PAXG paper account daily signal** → Run workflow，选 `mode=signal`。它会更新模拟账本并创建 Issue，已包含 2026-02-01 的 10,000 USDT 历史模拟本金，**不需要再次 init**。每天 UTC 00:20 计划运行；GitHub Actions 可能延迟，不能保证在交易时点到达。
3. 仓库 Watch/Notifications 的 Email 需你自行开启并实际确认；GitHub **不保证**自己仓库由机器人创建的 Issue 一定发到邮箱。出错会尝试开错误 Issue，查看 Actions 日志；如账本 git push 失败，系统也会发失败警告。**通知中的模拟成交不会使交易所资金变化**。
4. GitHub 工作流的 `mode=init` 仅给新建空模拟账本使用，已提供账本的这个项目再次 init 会被拒绝，避免意外清空历史。

> PAXG 是黄金支持代币而非伦敦现货金，USDT、发行人和交易所存在额外风险。最大回撤 30% 是风控目标而非保证；日线跳空、流动性不足或价格异常都可能穿越限制。研究/重选会改写 `chosen.json`，模拟工作流检测到不再是已审定 EMA10/EMA50 时会**拒绝运行**，而不是悄悄改策略。

## 文件

- `data.py`, `paxg_daily.csv`：完整 UTC 日 K 抓取、校验及原始行情快照。
- `strategy.py`, `engine.py`, `research.py`：因果指标、次日开盘回测、训练/验证对照和熔断规则；研究明细在 `results/`。
- `chosen.json`：训练期固定的 EMA10/EMA50 参数；未经审定不能自动替换。
- `paper.py`, `paper_portfolio.json`, `paper_fills.csv`：自动计算交易额、模拟成交、账本和历史流水；**全部虚构成交**。
- `post_issue.py`, `.github/workflows/paxg.yml`：模拟账户每日 GitHub Issue 推送；`signal_latest.txt/json` 是最近一次模拟通知。
- `daily.py`：旧的手工登记工具（不被自动模拟工作流调用）。
- `tests/`：次日开盘、费用、熔断、因果数据及模拟账本测试。
